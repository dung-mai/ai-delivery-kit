# Recipe: spike / POC

1. Write the question and the decision it feeds, the time box, and what result means yes/no (`product/research/S-xx-<slug>.md`).
2. Experiment in a throwaway branch or folder `spikes/<slug>/`. Measure, do not polish.
3. Report: result, numbers, limits of the experiment, recommendation. Update the decision card. Gate **conclusion**.
Spike code is not merged into the product without going through plan and build.
